# Licensing Before Public Release

Review ownership and licenses for all code, user-provided HTML, embedded scripts, screenshots, fonts, images, and bundled libraries before redistributing the full archive. Inspecting a user-provided file does not grant redistribution rights.

- Identify original authors and third-party assets.
- Check license and attribution requirements.
- Remove embedded personal data, credentials, cookies, and private URLs.
- Choose a repository license only after defining what it covers.
- Do not imply a repository license re-licenses excluded third-party assets.
- Record exclusions and provenance in the artifact catalog.
- Review dependencies and pinned GitHub Actions before enabling public deployment.
