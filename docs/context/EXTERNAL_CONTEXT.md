# External Reviewer Context

Try to falsify the claim that the reviewed Proofline revision reliably checks an AI-assisted deliverable.

## Questions

- Which claims are directly supported by source/test evidence and which are inferred?
- Which tests reuse the implementation's assumptions?
- Are inputs and outputs reconciled independently?
- Does a CSV export contain exactly the filtered source rows?
- Are interactive controls tested in a real browser?
- What are the most credible data-loss, privacy, false-confidence, and failure modes?
- Is the deliverable commercially useful, or has scope become overbuilt?

## Required report

Rank findings by blocking/major/minor/suggestion. Include evidence, impact, reproduction, and proposed verification. Separate observed behavior from inference. End with accept / accept with follow-ups / revise / stop and one highest-value next action. Disclose whether the reviewer authored the implementation or used the same context/model.
